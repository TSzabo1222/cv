Asset Manager

A full-stack IT asset management system: track company hardware, assign it to employees, manage inventory stock, and see a full audit trail of every change — all behind JWT-secured login. Built as an ASP.NET Core Web API with an Angular + Material front end.

  • JWT authentication — register/login, hashed passwords (BCrypt), protected routes on both frontend and backend
  • Full CRUD for Assets, Employees, and Inventory, each with its own data model
  • Assign/return workflow with a complete assignment history log per asset

  • Light & dark mode with an animated theme toggle and saved preference
  • REST API documented and testable via Swagger / OpenAPI
  • SQL Server database via Entity Framework Core, with migrations
  • Organised as separate API and UI projects in the same repository
